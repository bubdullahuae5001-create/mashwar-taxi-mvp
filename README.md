# مشوار — Taxi Request MVP

نسخة MVP عربية RTL لطلب سيارة أجرة بدون خرائط أو دفع أو تتبع.

## الملفات
- `index.html` واجهة العميل
- `admin.html` لوحة الإدارة
- `styles.css` التصميم
- `app.js` إرسال وتأكيد الطلبات
- `admin.js` إدارة الطلبات والسائقين
- `supabase.sql` قاعدة البيانات والسياسات
- `config.example.js` مثال الإعدادات
- `config.js` تنشئه أنت من المثال وتضع مفاتيح Supabase

## 1) إعداد Supabase
1. أنشئ مشروعًا مجانيًا في Supabase.
2. افتح SQL Editor والصق محتوى `supabase.sql` ثم Run.
3. من Project Settings > API انسخ Project URL و anon/public key.
4. انسخ `config.example.js` إلى ملف باسم `config.js` وأدخل القيم.
5. من Authentication > Users أنشئ مستخدم مدير بالبريد وكلمة المرور.

> لا تضع `service_role` key في الموقع إطلاقًا. استخدم anon key فقط.

## 2) التشغيل محليًا
يفضل تشغيله عبر خادم محلي بدل فتح HTML مباشرة:

```bash
python -m http.server 8080
```
ثم افتح:
- العميل: http://localhost:8080/
- الإدارة: http://localhost:8080/admin.html

## 3) النشر
أبسط خيارين:
- Netlify Drop: ارفع مجلد المشروع كاملًا بعد إنشاء `config.js`.
- Vercel: أنشئ Static Project وارفع الملفات.

لا يوجد Backend خاص بك؛ المتصفح يتصل مباشرة بـ Supabase مع RLS.

## 4) دخول لوحة الإدارة
افتح `/admin.html` وسجل بالبريد وكلمة المرور اللذين أنشأتهما في Supabase Authentication.

## 5) إضافة السائقين
بعد دخول الإدارة، استخدم قسم "السائقون": الاسم، الهاتف، رقم السيارة، النوع، والتوفر.

## 6) تجربة طلب حقيقي
1. افتح الصفحة الرئيسية من الهاتف.
2. املأ الاسم والانطلاق والوجهة والهاتف والركاب.
3. اضغط "إرسال طلب سيارة".
4. راجع الملخص واضغط "تأكيد الطلب".
5. سيظهر رقم طلب.
6. افتح لوحة الإدارة: سيظهر الطلب بحالة "جديد".
7. عيّن سائقًا وغيّر الحالة.
8. استخدم زر واتساب لإرسال تفاصيل الطلب للسائق، أو الاتصال بالعميل.

## تغيير الاسم
غيّر `APP_NAME` في `config.js`، ويمكنك تغيير الحرف داخل `brand-mark` في `index.html` و`admin.html`.

## ما لا يتضمنه هذا الـMVP
لا GPS، لا خرائط، لا تتبع، لا دفع، لا تقييم، لا مطابقة آلية، لا ذكاء اصطناعي، ولا تسعير ديناميكي.
